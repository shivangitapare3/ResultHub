# ResultHub

ResultHub is a web-based Student Result Management System developed using Python and Flask. It helps manage student information, marks, and examination results through a simple web interface.

## Features

- Student result management
- Student information management
- Marks and result calculation
- Result viewing
- PDF result generation
- PostgreSQL database integration
- Simple and user-friendly interface

## Technologies Used

- Python
- Flask
- PostgreSQL
- HTML
- CSS
- JavaScript
- ReportLab
